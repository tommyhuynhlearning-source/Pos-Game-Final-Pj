    05Dependency cascade — lỗi lan xuôi, fix đi ngược

    Bấm một module để giả lập nó hỏng: downstream chuyển Blocked (ẩn clue), module đang hỏng là Error (luôn phải chẩn đoán được). Phân biệt sai hai cái này là bug từng gặp với P6/P7.

    Mọi module đang OK. Bấm một module để inject fault.

    Nằm ngoài cascade

    • Staff login — POS Manager ▸ Staff Management. Terminal OK, mọi người khác OK, mà một nhân viên vẫn không vào được (role / assignment riêng).
    • Database — POSSoftware.dbHost, POS Manager ▸ Connections. Check độc lập, không nằm trên chain Terminal/Printer.
